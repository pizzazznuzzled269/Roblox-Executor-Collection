## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors packaged together for convenience. It includes Volt, Synapse Z, Potassium, Wave, and a universal loader called xcutorsLoader.

### Is XCutors free to use?

The loader itself is free and open-source. However, some individual executors included may have their own licensing or subscription requirements. Please check each executor's official page for details.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions like Windows 7 or 8 may work but are not officially supported.

### Why does my anticomponent flag the loader?

Some anticomponent software may flag script executors as potentially unwanted programs due to their memory-injection behavior. This is a false positive for legitimate executors. You may need to add an exception in your anticomponent settings.

### How do I update the executors?

The xcutorsLoader includes an automatic update checker. You can also manually update by downloading the latest release from this repository and replacing your existing files.

### Can I add my own scripts to the library?

Yes! Navigate to the Scripts folder in your installation directory and add your .lua files. They will appear in the script library the next time you launch the loader.

### Which executor should I choose?

Each executor has different strengths. Volt is known for speed, Synapse Z for script compatibility, Potassium for its UI, and Wave for stability. Try each one to see which works best for your needs.

### I'm getting a connection error when attaching. What should I do?

Make sure Roblox is running and you're in a game before attaching. Also ensure you're running the executor as Administrator and that your firewall isn't blocking the connection.

### Where can I find scripts to use?

You can find community-shared scripts on GitHub, script-sharing forums, and Discord servers. The built-in script library also includes popular utility scripts to get you started.
